# 런검정

런은 같은 종류의 값이 연속되는 덩어리입니다.

```text
HHH | TT | HH | TTTT | H
```

위 순서에는 런이 5개 있습니다. 런검정은 두 종류의 관측값 개수가 주어졌을 때 런의 수가 무작위 순서에서 기대되는 범위에 있는지 평가합니다.

- 런이 지나치게 적음: 같은 값들이 군집되어 있을 수 있음
- 런이 지나치게 많음: 지나친 교대 패턴이 있을 수 있음

생산공정의 불량 발생, 시계열의 부호, 회귀잔차의 순서가 무작위적인지 점검할 때 사용할 수 있습니다. 런검정은 값의 크기보다 순서 정보를 사용하며, 독립성의 모든 형태를 검출하는 만능 검정은 아닙니다.

> [!summary] 한마디 비유
> 런검정은 **빨강·검정 카드의 순서를 보고 카드가 충분히 섞였는지 의심해 보는 검사**입니다.
